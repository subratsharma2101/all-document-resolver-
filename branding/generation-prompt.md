# File Viewer production icon

Tool: built-in image generation, opaque output.
Asset: `fileviewer-icon.png` (used in the workspace header and native app config).

## Final prompt

Use case: logo-brand. Asset type: production app icon for the existing mobile app File Viewer, a private on-device document reader, scanner and editor. Create a striking, professional, exceptionally clean geometric logo, a single folded document mark whose clever negative space suggests an F, with one subtle layered page behind it. Strong distinctive silhouette legible at 24 pixels. Palette matches the new app UI: solid very deep teal background #102F36 edge-to-edge, main paper ivory #F8F6F0, small vivid mint #78DFC1 folded corner accent. Flat precise vector-like graphic with impeccable optical alignment, softly rounded corners on the paper mark, no gradient, no glossy plastic, no 3D mockup. Square 1024 by 1024 canvas. Center the entire mark within the middle 56% of width and height so Android circular and squircle adaptive masks have generous safe area. The background fills the entire square, do not draw an outer rounded icon container or any border. No text, no letters printed on the paper, no watermark, no additional tiny lines or stars. One finished app icon, not a presentation board or multiple variants.

The generated monochrome experiment was discarded after visual review; the approved
color icon is the production asset. Adaptive icons use its centered safe-area mark.
